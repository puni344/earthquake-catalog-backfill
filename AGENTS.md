# Project scoring instructions

[SOURCE: project owner, original D2 engineering brief, rule R10] Verbatim scoring rule:

R10 SCORING WITH ANCHORS. /100 (relevance 20, depth 20, production readiness 20, differentiation 15, demonstrability 15, cost/repro 10). Each line cites an artifact. Caps: production readiness max 12/20 unless MVP includes a load test AND an incident drill; relevance max 12/20 if data is synthetic; differentiation max 8/15 if the signature problem has no measured result; cost/repro max 5/10 if it does not run with one command. Honest range for a student project is about 55–80; above 85 needs written justification.
