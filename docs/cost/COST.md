# Earthquake catalog cost and CI

Budget approved for this project: ₹0. Local documentation checks require GNU Make and Python's standard library. The simpler local-only option cannot independently check a proposed change in a pull request.

Use a standard GitHub-hosted `ubuntu-24.04` runner only when the event identifies the repository visibility as `public`. The job-level condition must evaluate before allocating the runner. Use read-only checkout permissions, a short timeout and console output. The workflow requires no cache, uploaded artifacts, cloud account or paid runner. Until a public run is authorized and observed, hosted execution is **NOT RUN**.

[SOURCE: GitHub, checked 26 November 2026] Standard runners in public repositories use the free route. Private or internal repository usage depends on allowances and larger runners can incur charges.
